# Общие темы TUI

Все приложения на ktuilib читают `/ETC/TUI.THM` при первом рисовании.
Ctrl+T открывает общий выбор темы из `/ETC/THEMES` в любом TUI.
Выбранная тема сохраняется в `/ETC/TUI.THM`; ошибка записи сохраняет прежнюю палитру.
Невалидный файл не меняет текущую палитру.
Новый процесс получает актуальную тему. Обновление установщика сохраняет
пользовательский `/ETC/TUI.THM`, а примеры обновляет в `/ETC/THEMES`.

Формат намеренно минимален: одна замена VGA-атрибута на строку:

```text
# Светлый фон вместо синего
17=70
1F=70
1E=71
70=1F
```

Ровно две hex-цифры, `=`, две hex-цифры. Регистр не важен. Пустые строки и
строки, начинающиеся с `#`, пропускаются. Поддерживаются LF и CRLF, без пробелов
вокруг `=`. Неуказанные цвета остаются исходными, последняя запись побеждает.
Лимит файла 2048 байт; при любой ошибке весь файл отвергается.

Старшая цифра — фон, младшая — цвет текста (стандартные VGA-индексы 0–F).
Для фона рекомендуется 0–7: старший бит на VGA может включать мигание.

Основные исходные атрибуты: `07` текст редактора, `17` фон панелей,
`1F` основной текст, `1E` акценты, `70` выделение/статус/диалоги,
`08` тени и scrollbar, `2F` заполнение gauge. Подсветка использует также
`0A/0B/0E` и `1A/1B/1E`, номера строк — `08`.
Преобразование применяется только при передаче кадра: вложенные диалоги
сохраняют исходные цвета и корректно переживают смену темы.

Готовые темы: DARK, LIGHT, AMBER и FOREST в `system/themes/`.
В любом открытом TUI нажмите Ctrl+T и выберите тему стрелками и Enter;
Esc отменяет выбор. В vik также есть `:theme`.
Новые процессы читают сохранённый выбор; уже открытые другие процессы
не получают автоматического уведомления о смене темы.

## KTTE — Kintsugi TUI Theme Editor

Запуск: `ktte` или `ktte /ETC/THEMES/LIGHT.THM`. Также доступен в launcher
KTUI клавишей 7. Новый документ изначально содержит текущую палитру.

По умолчанию включён **простой режим**: выберите фон рабочего поля, панели,
текст, акценты, редактор, выделение, всплывающие окна, тени или индикаторы.
Enter открывает список цветов с названиями и образцами; Tab переключает текст/фон.
Выбранная строка меню и выбора цвета помечена `>`; выделение автоматически
получает читаемый контраст, если цвета темы совпали с фоном окна.
В выборе цвета Up/Down и Left/Right перемещают выбор, Enter подтверждает,
Esc отменяет без изменения цвета.
Для первых двух пунктов редактируется только фон. Фон панели меняет фон
всей группы её цветов, сохраняя цвета текста. `m` переключает простой и
расширенный режим (все 256 атрибутов).

При сохранении достаточно ввести `mytheme`: KTTE создаст
`/ETC/THEMES/MYTHEME.THM`. Указанный путь также нормализуется в каталог тем;
другие расширения и имена длиннее 8 символов отвергаются. Это гарантирует,
что сохранённый файл попадает в каталог общего выбора Ctrl+T.
Общий выбор поддерживает до 64 тем, с прокруткой PageUp/PageDown.
Отдельные роли `71` (popup) и `72` (desktop) позволяют менять их независимо;
в старых темах они наследуют `70` и `17` соответственно.

- Up/Down, PageUp/PageDown, Home/End — выбор исходного атрибута из 256.
- Tab — переключить редактирование цвета текста/фона.
- Left/Right или `0–9`, `a–f` — изменить выбранную hex-цифру.
- `n` — новая исходная палитра; `o` — открыть файл темы.
- `s` — сохранить; `w` — сохранить под другим именем.
- Shift+A — сохранить и применить как `/ETC/TUI.THM`.
- `h` — справка: названия и образцы всех 16 цветов, устройство атрибута,
  основные роли цветов TUI и предупреждение о мигании фонов 8–F.
- `q` / Esc — выход, с подтверждением при несохранённых изменениях.

Образцы показывают настоящие VGA-цвета без повторного преобразования темой.
Сохраняйте пользовательские темы как `/ETC/THEMES/NAME.THM` (ASCII 8.3),
чтобы они появились в общем выборе Ctrl+T. KTTE сохраняет все 256 отображений
в формате `XX=YY` (1536 байт); комментарии исходного файла не сохраняются.
При сохранении под другим именем существующий файл требует подтверждения.

## Прокрутка и стабильность ввода

PageUp/PageDown работают в редакторах kuned/vik, списках KC, KPROCM и меню.
Home/End в списках выбирают первую/последнюю запись. Shift+Up/Down в редакторах
перемещают на логическую строку. Это клавиатурная прокрутка, не колесо мыши.

## Vik

`vik /HOME/TEST.TXT` — отдельный ELF, собираемый из общего движка kuned.
Нет дублирования загрузки, сохранения, undo, поиска и отрисовки.

- Normal: `h/j/k/l`, `0/$`, `gg/G`, стрелки и PageUp/PageDown.
- `i` — insert, `a` — insert после символа, `o` — новая строка ниже.
- Esc — из insert в normal, `x` — удалить символ, `u` — undo.
- `/` — поиск, `n` — следующий результат.
- `:w`, `:w PATH`, `:q`, `:q!`, `:wq` — запись и выход.
- `I/A` — вставка в начале/конце строки, `w/b` — движение по словам,
  `dd` — удалить строку. Команды kuned вроде Ctrl+S/Ctrl+Q отключены.
- `/` и `:` используют нижнюю командную строку, а не диалог kuned.

Это небольшое Vim-подобное подмножество, не реализация Vim: нет visual,
регистров, макросов и числовых префиксов; из операторов удаления есть `dd` и `x`.

## Shell scrollback

В userspace-shell Shift+Up/Down прокручивают вывод построчно, PageUp/PageDown —
по 23 строки. Обычный ввод возвращает к текущему приглашению; стрелки без Shift
сохраняют редактирование и историю команд. Буфер остаётся ограничен 200 строками.
Автоматическая прокрутка и возврат к приглашению используют одну позицию
нижней границы экрана. Строка ввода перерисовывается одной записью, а VGA
обновляет только изменившиеся ячейки, без промежуточного стирания строки.

## Снимок процессов

Syscall 16 возвращает согласованный ограниченный снимок при отключённых IRQ:
PID, PPID, состояние, ticks, committed user heap, process group, имя ELF.
Структура `kos_process_info` расширена: ядро и приложения обновляются вместе.
Имя ограничено 31 байтом и всегда NUL-терминировано, указатели ядра не выдаются.
Ticks — время планирования, включая исполнение ядра от имени процесса,
не достоверный процент CPU. Heap — закоммиченный диапазон пользовательской кучи,
не суммарная память процесса.

KPROCM сохраняет выбор по PID при обновлении, S переключает сортировку PID/ticks,
Space замораживает снимок, Enter показывает значения выбранного процесса.
Закрывшийся процесс исчезает после reap; безопасного интерфейса kill пока нет.

## Проверки

`make test-tui` проверяет PageUp/PageDown, валидацию тем, CRLF, повторные ключи
и сохранение палитры при ошибке. `python3 tools/smoke_test.py --light-theme`
проверяет реальные VGA-атрибуты общей светлой темы в QEMU.
Основной smoke-test проверяет details KPROCM, прокрутку и запись файла через vik.
