# Общие виджеты и командерное управление

## Библиотека

`ktuilib` предоставляет окна с clipping, вложенные модальные окна, меню,
списки с прокруткой, полосы прогресса и следующие переиспользуемые виджеты:

- `tui_input`: ограниченный NUL-terminated буфер, курсор, Home/End,
  Left/Right, Backspace/Delete, вставка в середину и горизонтальная прокрутка;
- `tui_button`: обычное, сфокусированное и disabled-состояние;
- `tui_checkbox`, `tui_radio`: отображение состояния;
- `tui_toggle_key`, `tui_focus_key`: Space для переключения и Tab для обхода;
- `tui_list_draw`: общий список с маркером выбора и scrollbar.

Поле ввода не владеет буфером; capacity включает завершающий NUL. Перед
отрисовкой буфер должен быть корректной строкой. Radio рисует один элемент,
а взаимоисключение элементов группы контролирует приложение.
В KTUI клавиша H открывает интерактивный пример виджетов.
Общие prompt/confirm/message используют новые поля и кнопки.

## Роли тем

Старый формат `XX=YY` и все прежние атрибуты сохраняются. Новые роли:

| Ключ | Назначение |
|---|---|
| 73 | Поле ввода |
| 74 | Кнопка |
| 75 | Фокус |
| 76 | Недоступный элемент |
| 77 / 78 / 79 | Ошибка / предупреждение / успех |
| 7A / 7B / 7C | Маркировка файлов / каталог / рамка |
| 7D / 7E / 7F / 80 | Комментарий / строка / число / ключевое слово |
| 81 / 82 | Visual-выделение / статус (доступная роль для приложений) |

Отсутствующие роли наследуют соответствующие старые цвета, а не отображаются
как VGA-атрибут собственного номера. KTTE позволяет редактировать эти роли
в прокручиваемом простом режиме и сохраняет все 256 отображений.
Не каждый старый жёстко заданный цвет приложений заменён семантической ролью.

## KC

F1 справка, F2 сведения, F3 просмотр, F4 редактор, F5 копирование,
F6 перемещение, F7 mkdir, F8 удаление, F9 настройки, F10 выход.
Прежние буквенные команды работают. Tab меняет панель, T создаёт вкладку,
`[`/`]` переключают, X закрывает вкладку, `/` открывает каталог.

Insert или Space маркируют запись и переходят к следующей; `+` маркирует все,
`-` снимает маркировку. Родитель `..` не маркируется. C/M/D и F5/F6/F8
применяются к отмеченным записям, а при отсутствии отметок — к текущей.
Перед групповой операцией требуется подтверждение. При частичном успехе
показывается отдельное сообщение; отката нет. Маркировка привязана к именам,
при смене каталога сбрасывается.

Это не полная копия MC: нет рекурсивного копирования/удаления, перезаписи
существующих целей, VFS архивов и удалённых ФС. Действуют ограничения FAT12
ASCII 8.3, до 256 записей в панели и четыре вкладки.

## Vik и kuned

Vik не использует Ctrl+Q и Ctrl+S. Выход: `:q`, `:q!`, сохранение: `:w`,
`:w PATH`, `:wq`. Esc возвращает из insert в normal, из visual — снимает выбор.

Дополнительно к прежним командам:

- `h/j/k/l`, `w/b/e`, `0/^/$`, `G`, `числоG`, числовые повторы движений;
- `d/c/y` + движение, `dd/cc/yy`, числовые повторы операторов (`2dw`, `d2w`);
- `D/C`, `x`, `p/P`, `v/V` с `d/c/y`;
- `"a`–`"z` выбирают регистр следующего yank/delete/paste;
- `u` и Ctrl+R переключают undo/redo (восемь снимков).

Именованные регистры независимы; совместимость со всеми специальными
регистрами Vim не заявляется. Insert пока сохраняет снимок на каждый символ,
а не на всю сессию вставки. Нет regex, macros, dot-repeat, text objects,
split windows, plugins, полной Ex-грамматики и полной семантики курсора Vim.
Редактор ограничен 64 КиБ. Read-only запрещает изменение через операторы.

Оба редактора выбирают подсветку по расширению: C/H/CPP/JS/TS, ASM/S/INC,
SH/PY, CFG/INI/THM; остальные файлы — обычный текст. Лексер различает строки,
числа, базовые ключевые слова и комментарии соответствующего семейства,
включая многострочные C-комментарии. Это не полноценный парсер языка.

KPROCM/KDISKMAN/KTUI поддерживают F1 и F10; KDISKMAN показывает состояние
тома через роли успеха/ошибки. Изменены клавиатурные события: пересобирайте
ядро и системные ELF вместе.
