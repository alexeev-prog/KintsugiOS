# Hieroglyph — текстовые документы

Запуск: `hieroglyph /HOME/NOTE.MD` или `hiero /HOME/NOTE.MD`.
Без пути создаётся новый документ. Отсутствующий файл открывается как новый;
существующий — в режиме чтения. В KTUI: пункт 9.

Исполняемый файл `/BIN/HIERO.ELF`: полное имя не помещается в FAT 8.3,
поэтому `hieroglyph` — явный псевдоним shell.

## Управление

| Клавиша | Действие |
|---|---|
| F1 | Справка по разметке |
| F2 | Сохранить |
| F3 | Чтение / написание |
| F4 | Сохранить как |
| F10 / Esc | Выход; при изменениях — подтверждение отказа от них |
| Ctrl+T | Общая тема |
| Ctrl+Z / Ctrl+R | Undo / redo в режиме написания |

В чтении: стрелки, PgUp/PgDn, Space, Home/End. Справа scrollbar,
внизу номер экранной страницы. Это не печатная пагинация.
В написании: стрелки, Home/End, PgUp/PgDn, Backspace/Delete, Enter и Tab
(четыре пробела). Длинные строки визуально переносятся без изменения файла.
Вертикальные движения редактора идут по исходным строкам, не экранным переносам.

F3 показывает текущий буфер без необходимости сохранять его. После сохранения
путь обновляется; при ошибке буфер и отметка изменений остаются. Save as
спрашивает подтверждение замены существующего файла.

## Разметка

````text
# Заголовок
## Подзаголовок

Абзац с **выделением**, *акцентом* и `кодом`.

- Первый пункт
- Второй пункт

1. Нумерованный пункт

> Цитата

---

```c
int main(void) { return 0; }
```
````

В текущей ОС текст отображается печатным ASCII: примеры на русском иллюстрируют
синтаксис, но для корректного отображения содержимого используйте ASCII.
Заголовки и inline-выделение обозначаются цветами общих ролей темы; настоящего
курсива/изменения размера шрифта в VGA text mode нет. Цитаты имеют боковой
маркер, списки — маркеры, разделители и code fences — горизонтальные линии.
Внутри code fences inline-разметка не интерпретируется. Нумерованные списки
сохраняют явно записанную нумерацию. Пустые строки разделяют абзацы;
исходные переводы строк сохраняются при отображении.

Это небольшой Markdown-поднабор, не CommonMark: нет вложенных списков,
таблиц, ссылок, изображений, HTML и встроенного выполнения команд.

## Общие виджеты ktuilib

`tui_editor` — владеющий историей, но не текстовым буфером многострочный виджет.
Caller предоставляет `text[capacity+1]`, длину и завершающий NUL. Состояние
нужно обнулить перед использованием. До восьми undo/redo-снимков; на каждое
изменение создаётся один снимок. Ошибка выделения памяти не меняет текст.
`tui_editor_destroy` освобождает историю; буфер освобождает приложение.

`tui_document_key` — ограниченная прокрутка документа, используется также pager.
`tui_markdown` — общий проход layout/render: при height=0 только считает строки,
при ненулевой высоте рисует окно документа. Все этапы используют один перенос.
Реализация находится в `src/user/tuidoc.c`, включается в ktuilib и отдельно
не компилируется, чтобы сохранить простой механизм линковки TUI-программ.

Документ ограничен 64 КиБ. Чтение принимает CRLF и нормализует его в LF;
сохранение использует LF. Бинарные NUL отвергаются. История не сохраняется
между запусками; undo пока посимвольный. Отметка изменений консервативная:
возврат через undo к сохранённому тексту не снимает её автоматически.
