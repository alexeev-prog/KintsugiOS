# TUI-приложения и ktuilib

Все приложения — самостоятельные ELF32 в ring 3, устанавливаются в `/BIN`
через `make system-install` (также выполняется при `make run`).

## kuned — Kintsugi Universal Editor

`kuned /HOME/NOTE.TXT` или `./BIN/KUNED.ELF /HOME/NOTE.TXT`.
Без аргумента создаётся новый буфер с запросом пути при сохранении.

- Ввод текста, Enter, Backspace/Delete, стрелки, Home/End.
- Ctrl+S — сохранить; Ctrl+Q/Esc — выход с подтверждением потери изменений.
- ASCII, LF, до 64 КиБ. Имена файлов — FAT 8.3.
- Нет undo, поиска, UTF-8 и табуляции. Длинные строки переносятся по 80 колонкам;
  вверх/вниз перемещают по логическим строкам, не по визуальным переносам.
- При открытии ошибки чтения не превращаются в пустой буфер. Слишком большой
  файл и каталог отклоняются. Сохранение сообщает об ошибках VFS.

## kbsm — Kintsugi Basic System Monitor

`kbsm`: живые показатели usable RAM, свободных и выделенных физических страниц,
использованной/свободной/закоммиченной кучи ядра. Q/Esc — выход.
Обновляется при пробуждении CPU (обычно PIT, 50 Гц).
Не выдаёт выдуманную загрузку CPU или список процессов: ОС пока исполняет
одну foreground-программу. Собственные страницы приложения входят в PMM allocated.

## KC — Kintsugi Commander

`kc`: минимальный однопанельный файловый менеджер.

- Стрелки — выбор, Enter — вход в каталог, Backspace — родитель.
- C — копировать файл, M — переместить/переименовать.
- D — удалить с подтверждением; каталог должен быть пустым.
- N — создать каталог, Q/Esc — выход.
- Назначение: абсолютный путь или имя относительно открытой панели.
- Нет перезаписи цели, рекурсивного копирования, запуска/редактирования файлов.
- Отображает первые 512 записей; порядок соответствует каталогу на диске.
- Навигация панели не меняет текущий каталог shell.

## ktuilib — Kintsugi TUI Library

`src/user/ktuilib.h`, `ktuilib.c` — статически линкуемая пользовательская библиотека.
Буфер 80×25 ячеек символ/цвет, безопасное обрезание при выводе, цветные строки,
числа, статусные панели, чтение raw-клавиш, диалог строки, подтверждение,
небольшие файловые помощники. Общие wire-типы — `src/user/tuiabi.h`.
Прямой доступ к VGA пользовательским приложениям не предоставляется.

При первом показе кадра ядро сохраняет терминал; при выходе/падении приложения
восстанавливает его. Не используется ANSI-парсер или альтернативный shell editor.

Расширения syscall ABI:

| № | Назначение | ebx / ecx / edx |
|---|---|---|
| 7 | present | 2000 ячеек / cursor x / cursor y |
| 8 | key | 0 poll, 1 blocking, 2 до следующего IRQ |
| 9 | memory snapshot | указатель ktui_stats |
| 10 | replace file | path / data / size ≤65536 |
| 11 | filesystem operation | path / operation / output |
| 12 | copy/move | source / destination / 0 copy, 1 move |

Операции №11: 0 mkdir, 1 unlink, 2 rmdir, 3 chdir, 4 stat.
Все пользовательские диапазоны проверяются до обращения к ним.

Smoke-test запускает все три TUI, сохраняет файл через kuned и проверяет
возврат в shell; затем внешний fsck проверяет образ.
