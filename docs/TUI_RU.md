# TUI-приложения и ktuilib

Общие файловые темы, прокрутка, редактор **vik** и расширенный снимок процессов:
[THEMES_RU.md](THEMES_RU.md).

Все приложения — самостоятельные ELF32 в ring 3, устанавливаются в `/BIN`
через `make system-install` (также выполняется при `make run`).

## kuned — Kintsugi Universal Editor

`kuned /HOME/NOTE.TXT` или `./BIN/KUNED.ELF /HOME/NOTE.TXT`.
Без аргумента создаётся новый буфер с запросом пути при сохранении.

- Ввод текста, Enter, Backspace/Delete, стрелки, Home/End.
- Ctrl+S — сохранить; Ctrl+Q/Esc — выход с подтверждением потери изменений.
- ASCII, LF, до 64 КиБ. Имена файлов — FAT 8.3.
- Ctrl+Z — undo последних восьми изменений (снимки в пользовательской куче).
- Ctrl+F — поиск подстроки с обходом конца файла, Ctrl+N — следующий результат.
- Ctrl+R — замена одного совпадения непустой строкой; Ctrl+G — переход к строке.
- Ctrl+A — сохранить как; путь меняется только после успешной записи.
- В статусе — логическая строка, колонка и размер буфера; стрелки вверх/вниз
  сохраняют логическую колонку, в том числе в строках с визуальным переносом.
- Tab — четыре пробела, Ctrl+E — справка, Ctrl+O — настройки номера строк/темы.
- Простая лексическая раскраска чисел, строк, скобок и комментариев `;`.
  Это не полноценный анализатор C или Lisp.
- `kuned PATH --readonly` — просмотр без изменения или сохранения файла.
- Нет redo и UTF-8. Длинные строки переносятся по ширине области текста;
  вверх/вниз перемещают по логическим строкам, не по визуальным переносам.
- При открытии ошибки чтения не превращаются в пустой буфер. Слишком большой
  файл и каталог отклоняются. Сохранение сообщает об ошибках VFS.

## kbsm — Kintsugi Basic System Monitor

`kbsm`: живые показатели usable RAM, свободных и выделенных физических страниц,
использованной/свободной/закоммиченной кучи ядра. Q/Esc — выход.
Обновляется при пробуждении CPU (обычно PIT, 50 Гц).
Показывает количество процессов, но не выдуманную загрузку CPU.
Space приостанавливает обновления, D переключает пояснение учёта памяти.
Собственные страницы приложения входят в PMM allocated.

## KC — Kintsugi Commander

`kc`: двухпанельный файловый менеджер, до четырёх вкладок на панель.

- Стрелки/Home/End — выбор, Enter — вход в каталог или редактор, Backspace — родитель.
- Tab — другая панель, T — новая вкладка, [ / ] — смена вкладки, X — закрыть.
- B — предыдущий каталог, / — перейти по абсолютному пути.
- V — read-only просмотр через kuned, R — переименование, I — атрибуты.
- C — копировать файл, M — переместить/переименовать.
- D — удалить с подтверждением; каталог должен быть пустым.
- N — создать каталог, Q/Esc — выход.
- Копирование и перемещение — в каталог другой панели, с подтверждением.
- Нет перезаписи цели и рекурсивного копирования.
- До 256 записей на панель (включая `..`), сортировка по имени, каталоги первыми.
- O — настройки размеров/сортировки; H — справка. Настройки в `/ETC/KC.CFG`.
- Настройки редактора и KC выбираются стрелками и Enter в общем меню.
- Навигация панели не меняет текущий каталог shell.

## ktuilib — Kintsugi TUI Library

Оконный слой: `tui_window` с геометрией, заголовком, рамкой, тенью и признаком
фокуса; `tui_window_text` обрезает вывод по клиентской области. Фокус переключает
само приложение (например, Tab в KC). `tui_modal_begin/end` сохраняют и
восстанавливают фон; допускается до четырёх вложенных диалогов без аллокаций.
Есть клавиатурное меню `tui_menu`, общая навигация `tui_list_key`, scrollbar.
Это библиотека окон внутри foreground-приложения, не межпроцессный compositor:
нет мыши, перетаскивания, изменения размера или одновременного показа разных ELF.

`src/user/ktuilib.h`, `ktuilib.c` — статически линкуемая пользовательская библиотека.
Буфер 80×25 ячеек символ/цвет, безопасное обрезание при выводе, цветные строки,
числа, статусные панели, чтение raw-клавиш, диалог строки, подтверждение,
небольшие файловые помощники. Общие wire-типы — `src/user/tuiabi.h`.
Прямой доступ к VGA пользовательским приложениям не предоставляется.

При первом показе кадра ядро сохраняет терминал; при выходе/падении приложения
восстанавливает его. Не используется ANSI-парсер или альтернативный shell editor.

Расширения syscall ABI:

| № | Назначение | ebx / ecx / edx |
|---|---|---|
| 7 | present | 2000 ячеек / cursor x / cursor y |
| 8 | key | 0 poll, 1 blocking, 2 до следующего IRQ |
| 9 | memory snapshot | указатель ktui_stats |
| 10 | replace file | path / data / size ≤65536 |
| 11 | filesystem operation | path / operation / output |
| 12 | copy/move | source / destination / 0 copy, 1 move |

Операции №11: 0 mkdir, 1 unlink, 2 rmdir, 3 chdir, 4 stat.
Все пользовательские диапазоны проверяются до обращения к ним.

## Остальные TUI

- `kprocm` — список процессов, выделение стрелками/Home/End, Enter — пояснение,
  Space — пауза, H — справка. Намеренно без небезопасного syscall kill.
- `kdiskman` — параметры FAT12, gauge занятости, C — read-only проверка ФС,
  Space — пауза, H — справка. Не форматирует и не меняет разделы.
- `ktui` — launcher: клавиши 1–5 или Enter и меню со стрелками; после завершения
  дочернего приложения возвращается в launcher.
- `klog`, `kfsck`, `proc` — консольные диагностические утилиты, не оконные TUI.

Smoke-test запускает шесть TUI, сохраняет файл через kuned и проверяет
возврат в shell; затем внешний fsck проверяет образ.
Дополнительно проверяет вложенный SHELL.ELF, Backspace, undo и поиск.
Каждая команда печатается с префиксом `[smoke]`; QMP имеет таймаут 10 секунд,
один сценарий — общий лимит 240 секунд. При ошибке выводится журнал serial.
`make test` запускает девять сценариев последовательно, поэтому полный прогон
занимает несколько минут; строка установки больше не последняя до его окончания.
